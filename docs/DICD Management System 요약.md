# DICD 측정 관리 시스템 개요

DICD (Developed Image CD) 측정 관리 시스템 - FastAPI 백엔드, HTML/JS 프론트엔드, MySQL 데이터베이스를 사용하는 한국 산업용 측정 데이터 관리 시스템입니다.

## 📊 핵심 기능

### 1. 데이터 관리
- 계층 구조: 제품군(ProductGroup) → 공정(Process) → 측정대상(Target)
- 측정 데이터: DICD 값, 시간, 장비, 오퍼레이터 기록
- 사양 관리: UCL/LCL, 공차 설정
- 장비 추적: 측정 장비별 데이터 관리
- ETCH 공정 지원: DICD/FICD 동적 전환 (공정 타입에 따라 텍스트 자동 변경)

### 2. 데이터 입력/업로드
- 개별 입력: 수동 데이터 등록 (조회 탭 제거 후 입력 탭 하단 인라인 편집으로 통합)
- 일괄 업로드: Excel 파일 대량 업로드
- 중복 검사: 자동 중복 데이터 검출
- PR 두께 측정: 포토레지스트 특수 측정
- 파티클(Particle) 측정: Y/O/B 크기별 파티클 수 측정 및 관리
  - 테이블형 데이터 입력 UI
  - Excel 과거 데이터 일괄 업로드
  - 장비 조치 사항 기록 및 관리
  - 측정 전 초안 조치 사항 기능

### 3. 통계 분석
- 분포 분석: 히스토그램, 정규분포 검정
- 박스플롯: 이상치 및 분산 시각화
- 추세 분석: 시간별 변화 추이
- SPC 분석: 관리도, Cp/Cpk 공정능력
  - Cp/Cpk: 합동 표준편차(Pooled Std Dev) 기반 단기 변동 계산
  - Pp/Ppk: 개별 위치값 전체 기준 장기 표준편차 계산
  - Cp/Cpk vs Pp/Ppk 차이 발생 시 잠재적 원인 자동 진단
- 변화점 탐지: 데이터 패턴 변화 감지
- Nelson Rules 위반 시 제조업 추정 원인 자동 표시

### 4. 파티클 분석
- 실시간 차트: Y/O/B 크기별 누적 막대 그래프
- 장비 조치 사항 마커: 차트에 역삼각형 마커 표시/숨김 토글
- SPEC 기준선 표시
- 차트 다운로드: PNG (24cm × 13cm 고정 크기, PPT 삽입 최적화)

### 5. 보고서
- PDF 생성: 분석 결과 리포트
- Excel 내보내기: 데이터 다운로드
- 통계 요약: 기술통계량 자동 계산
- 공정팀 양식 다운로드: SPC 분석 결과를 PNG 이미지로 저장 (24cm × 15cm, UCL/LCL 수동 입력 지원)

### 6. 시스템
- 캐싱: API 응답 캐시로 성능 최적화
- 다국어: 한국어 기반 인터페이스
- Windows 서비스: 운영 환경 서비스 등록
