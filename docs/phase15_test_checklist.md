## 4. 데이터 분리 검증 (간섭 테스트)

### 4.1 API 레벨 분리 확인
```
# PHOTO 타겟만 조회
GET /api/targets?process_type=PHOTO

# ETCH 타겟만 조회
GET /api/targets?process_type=ETCH

# 기본값 (PHOTO) 확인
GET /api/targets
```
- [ ] process_type 파라미터 없이 호출 시 PHOTO 데이터만 반환
- [ ] process_type=PHOTO 시 PHOTO 데이터만 반환
- [ ] process_type=ETCH 시 ETCH 데이터만 반환

### 4.2 데이터 생성 분리 확인
- [ ] PHOTO에서 생성한 타겟이 ETCH에 표시되지 않음
- [ ] ETCH에서 생성한 타겟이 PHOTO에 표시되지 않음
- [ ] PHOTO에서 생성한 장비가 ETCH에 표시되지 않음
- [ ] ETCH에서 생성한 장비가 PHOTO에 표시되지 않음

### 4.3 측정 데이터 분리 확인
- [ ] PHOTO에서 입력한 측정 데이터가 ETCH에 표시되지 않음
- [ ] ETCH에서 입력한 측정 데이터가 PHOTO에 표시되지 않음

### 4.4 localStorage 분리 확인
- [ ] 브라우저 개발자 도구 > Application > Local Storage 확인
- [ ] `trend_report_targets_PHOTO` 키 존재
- [ ] `trend_report_targets_ETCH` 키 존재 (ETCH에서 타겟 선택 후)
- [ ] 두 키의 데이터가 독립적
