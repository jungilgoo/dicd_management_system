# 작업 세션 요약 - 2025-01-19

## 문제 상황
ETCH 설정 페이지(Phase 9)와 데이터 입력 페이지(Phase 10)에서 PHOTO 공정의 데이터가 표시되는 문제 발생

## 원인 분석

### 1차 원인: `settings.html`에 `PROCESS_TYPE` 설정 누락
- `frontend/pages/etch/settings.html`에 `window.PROCESS_TYPE = 'ETCH'` 전역 설정이 없었음
- 사이드바 링크 경로도 일부 잘못됨 (`etch/analysis/` → `analysis/`로 수정 필요)

### 2차 원인: `etch_index.html` 사이드바 링크 경로 오류
- ETCH 메인 페이지의 사이드바 링크가 PHOTO 페이지(`pages/`)를 가리키고 있었음
- `pages/etch/`로 수정 필요

### 3차 원인 (핵심): `tabManager.js` URL 하드코딩
- 탭 시스템이 iframe으로 페이지를 로드
- `tabManager.js`의 `tabTypes` 객체에 모든 URL이 PHOTO 경로(`pages/...`)로 하드코딩됨
- ETCH 시스템에서도 PHOTO 페이지가 로드되는 근본 원인

  - PHOTO: `pages/...` 경로 사용
