## 진행 중인 작업

### 1. DEVICE 중복 확인 API 추가 (진행 중)
- **목적**: 사용자가 새로운 측정 데이터 입력 시 DEVICE명이 이미 존재하는지 확인
- **변경 사항**:
  - `backend/database/crud.py`: `check_device_exists()` 함수 추가
  - `backend/routers/measurements.py`: `/check-device` 엔드포인트 추가
  - 쿼리 파라미터: `device` (확인할 DEVICE명)
  - 응답: `{"exists": boolean, "device": string}`

### 2. 데이터 입력 페이지 DEVICE 검증 기능 (진행 중)
- **목적**: 폼 제출 시 DEVICE 중복 확인 프롬프트 표시
- **변경 파일**: `frontend/js/input.js`, `frontend/pages/input.html`, `frontend/pages/etch/input.html`
- **구현 내용**:
  - 폼 제출 전 API로 DEVICE 존재 여부 확인
  - DEVICE가 이미 존재하면 사용자에게 확인 메시지 표시
  - 사용자 동의 시 데이터 저장 진행
  - ETCH/PHOTO 페이지 모두에 적용

### 3. CRUD 함수 개선
- **파일**: `backend/database/crud.py`
- **변경**: `check_duplicate_measurement()` 함수 정리 및 `check_device_exists()` 함수 추가

### 4. Measurements API 확장
- **파일**: `backend/routers/measurements.py`
- **변경**: 기존 필터링 기능 유지 및 새로운 `/check-device` 엔드포인트 추가
