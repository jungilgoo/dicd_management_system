  ## 3. 프론트엔드: 저장 로직 수정                                                                                         
                                                                                                                           
  ### input.js 수정 흐름                                                                                                   
  1. 저장 버튼 클릭 시 `checkDeviceExists(device)` 호출                                                                    
  2. 존재하면 → 기존 로직대로 저장                                                                                         
  3. 존재하지 않으면 → 재입력 모달 표시
